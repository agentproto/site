These are the long-form, code-first companions to the [spec index](/docs)
and the [feature breakdown](/features). Each one takes a single real
mechanism, walks the code that implements it, and ends with a
**reproduce-from-a-cold-clone** section you can run yourself.

The discipline is the point: every code quote is checked against the real
source file it comes from, every number is one an actual run produced, and
where the system still has rough edges, the article says so rather than
smoothing them over.

## The pi arc

The three pieces below form one argument, told in escalating stakes. They
use [`earendil-works/pi`](https://github.com/earendil-works) — a small,
MIT-licensed coding agent with no ACP server and no MCP client — as a
deliberately hostile test case. If agentproto can turn *that* into a
first-class, supervisable, orchestrating citizen of a fleet, the adapter
model holds for anything.
